# Total Recall

The web was a place to discover. Rewind restores that spirit without restoring obsolete security protocols.

Experimental v0.2 source includes tabs, session-only private browsing, local history and favorites, four color-era presets, an animated loading indicator, synthesized connection sound, Wiby discovery, Wayback navigation, download status and a ChatGPT shortcut.

Not yet implemented: full era-specific icon sets, startup sequence, radio, arcade, screensavers, guestbooks, homepage builder, RSS, AI API interface, retro website adapters, full download manager and granular permissions. Private tabs share an in-memory session until app exit; downloads and popups are denied there. Regular downloads use Electron defaults. ChatGPT authentication remains unverified. No security audit or signed release.
